# Novel Architecture — Development Blueprint

**สถานะ: PROVISIONAL — ไม่ใช่ canon ของเนื้อเรื่อง**

## ระบบจัดเก็บนิยายที่เสนอ
- `canon/` — กฎโลก ระบบพลัง เวทมนตร์ คัมภีร์ และตัวละครที่ยืนยันแล้ว
- `development/` — พล็อต แนวคิดสำรอง คำถาม และสิ่งที่ยังต้องตัดสินใจ
- `characters/` — เพิ่มภายหลังเมื่อกำหนดตัวละครจริง (ชื่อ ประวัติ ความสัมพันธ์ เส้นทางพัฒนา)
- `plot/` — เพิ่มภายหลังสำหรับไทม์ไลน์ อาร์ก ปม/การเฉลย
- `chapters/` — เพิ่มภายหลังสำหรับต้นฉบับเรียงตอน
- `continuity/` — เพิ่มภายหลังสำหรับบัญชีเวทที่เรียนแล้ว เหตุการณ์ แผล/ต้นทุน และจุดขัดแย้ง

## โครงเรื่องระยะยาว (ข้อเสนอ)
| อาร์ก | หน้าที่ในเรื่อง | พัฒนาการด้านคัมภีร์ |
| --- | --- | --- |
| 1. จุดเริ่มต้น | พบคัมภีร์และเรียนรู้ศาสตร์ที่มนุษย์ใช้ได้ | บทเวทบนโลกและข้อจำกัด |
| 2. เข้าสู่วงการฮีโร่ | สัมผัสสังคมฮีโร่ ความขัดแย้งชื่อเสียง-ความสามารถ | เลือกเวทตามสถานการณ์ |
| 3. รอยแยกแรก | เผชิญเหตุการณ์ต่างมิติที่ไม่ใช่อาชญากรรมทั่วไป | หน้าเวทที่ไม่เคยแสดงเริ่มปรากฏ |
| 4. อำนาจที่ไม่เหมาะกับมนุษย์ | ต้องเลือกว่าจะเสี่ยงใช้/ดัดแปลงศาสตร์อันตราย | ข้อจำกัดของกายมนุษย์ |
| 5. วิกฤตระดับโลก | เชื่อมภัยจากโลกและมิติอื่น | ความเข้าใจและภาระความรับผิดชอบเพิ่มขึ้น |

ทั้งหมดเป็น **โครงสร้างการเล่าเรื่องที่เสนอ** ไม่ใช่เหตุการณ์ที่เกิดขึ้นแล้วใน canon

## ปรับตาม Canon ล่าสุด (สำคัญ)
โครงอาร์กเก่าในตารางข้างต้นที่เริ่มด้วยการพบคัมภีร์ **ไม่ใช่ทิศทางเปิดเรื่องแล้ว**: ให้เปิดหลังพระเอกพบ Codex และเรียนกับอาจารย์หญิงแล้ว โดยใช้เวทระดับ 1 คล่อง พบกลุ่มฮีโร่ฝึกหัดในการปะทะขนาดเล็ก และจึงเข้าสู่โรงเรียนฮีโร่นานาชาติในฐานะนักเรียนแลกเปลี่ยนจากสภาเวทมนตร์ ดู [canon/10](../canon/10-opening-and-hero-academy-entry.md) และ [canon/11](../canon/11-international-hero-academy.md)
