# CANON — Codex Aeternum

**ชื่อทางการ:** Codex Aeternum (โคเด็กซ์ อีเทอร์นัม)  
**ประเภท:** คัมภีร์ประหลาดที่พระเอกครอบครอง  
**สถานะ:** CANON

## ธรรมชาติ
Codex Aeternum **ไม่ใช่ผู้สร้างเวทมนตร์** และไม่ใช่เพียงตำราเขียนโดยจอมเวทคนหนึ่ง แต่เป็น **จุดร่วมและตะกอนของร่องรอยเวทมนตร์** ที่สะสมมาจากการใช้เวทตั้งแต่ยุคก่อกำเนิดจักรวาล

เวทจากหลายมิติ หลายยุค และหลายสิ่งมีชีวิตทิ้งร่องรอยซึ่งมาบรรจบกันในคัมภีร์นี้ จึงมีความเชื่อมโยงกับองค์ความรู้เวทจำนวนมหาศาล ทั้งศาสตร์ที่มนุษย์นำมาใช้ได้และศาสตร์ที่อันตรายต่อมนุษย์

## ความสัมพันธ์กับตัวเอก
- พระเอกเป็นผู้ครอบครองคัมภีร์
- คัมภีร์ทำหน้าที่เปิดเผยองค์ความรู้ที่สัมพันธ์กับสิ่งที่พระเอกเผชิญ
- **ความรู้ที่คัมภีร์เผยไม่ได้เท่ากับการได้รับพลังหรือความชำนาญฟรี**
- ประเด็นการใช้งานสำคัญคือพระเอกต้องเลือกบทเวท ปรับสมดุลความเสี่ยง เตรียมการ และตัดสินใจว่าเหมาะกับสถานการณ์ใด

## ขอบเขตของข้อเท็จจริง
ยังไม่ยืนยันรูปลักษณ์ วัสดุ ผู้สร้าง ความมีชีวิต/เจตจำนง ความสามารถสื่อสาร การล็อกหน้าโดยระดับพลัง ลักษณะสองภาคแสง-มืด หรือการเป็นผนึกของตัวตนใด ๆ — สิ่งเหล่านี้เป็นเพียงข้อเสนอที่ผ่านมา

## ความสัมพันธ์กับของขลัง
คัมภีร์มีลักษณะเป็นวัตถุลี้ลับเฉพาะทางที่เก็บและเปิดเผยความรู้ ไม่ได้ทำหน้าที่รับผลสะท้อนของเวททุกชนิดแทนพระเอกโดยอัตโนมัติ ดู [กฎของขลัง](09-arcane-artifacts.md)
