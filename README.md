## เปิดด้วย Obsidian
Clone repository แล้วเลือก **Open folder as vault** ที่โฟลเดอร์รากของ Hero จากนั้นเริ่มที่ [[indexes/home|Vault Home]] ลิงก์ทั้งหมดใช้รูปแบบ Obsidian Wikilinks และโน้ตข้อมูลมี YAML Properties
