# ต้นฉบับนิยาย Hero

พื้นที่นี้เก็บโครงบทที่ผู้สร้างอนุมัติและต้นฉบับที่จะเขียนภายหลัง การอนุมัติโครงไม่ทำให้ร้อยแก้วหรือรายละเอียดฉากใหม่เป็น Canon โดยอัตโนมัติ

- Canon ที่ยืนยันแล้วอยู่ใน [[canon/01-world|canon/]]
- แนวพัฒนาและโครงที่ยังรออนุมัติอยู่ใน [[development/part-01-volume-01-outline|development/]]
- ต้นฉบับภาค 1 เริ่มที่ [[manuscript/part-01/index|ภาค 1]]
- ทุกบทต้องมี Scene ID, chapter_status, ตัวละคร, Knowledge Ledger และ Event links
- บทสนทนา รายละเอียดฉาก ชื่อชั่วคราว และผลการกระทำในต้นฉบับเป็น PROSE_DRAFT จนกว่าผู้สร้างจะยืนยัน

## สถานะบท
- OUTLINE — มีจุดประสงค์และฉาก แต่ยังไม่มีร้อยแก้วเต็ม
- DRAFT_IN_PROGRESS — เริ่มเขียนแล้ว
- DRAFT_COMPLETE — มีต้นฉบับครบตามจังหวะของบท พร้อมแก้ไข
- REVISED — ผ่านการแก้รอบหนึ่ง
- LOCKED — ผู้สร้างล็อกฉบับสำหรับการผลิต (ไม่เท่ากับการเปลี่ยน Canon ทุกบรรทัด)
