# ChatGPT Writing Brief — ภาค 1 เล่ม 1

ใช้หน้านี้เมื่อเริ่มเขียนแต่ละตอนใน ChatGPT

## ขั้นตอนต่อหนึ่งตอน
1. อ่าน [[AGENTS]], [[CANON_POLICY]], Canon และ Event/Knowledge links ใน Chapter Note
2. เปิด Chapter Note จาก [[manuscript/part-01/volume-01/index|Volume index]]
3. เขียนทีละ Scene ID ตามลำดับ
4. ใส่ร้อยแก้วใต้หัวข้อ Manuscript Draft ในไฟล์บทนั้นเท่านั้น
5. รักษา chapter_status: DRAFT_IN_PROGRESS ระหว่างเขียน และ DRAFT_COMPLETE เมื่อครบทุกฉาก
6. สิ่งที่ต้องคิดเพิ่มให้ทำเครื่องหมาย PROPOSED หรือ TBD; อย่าแก้ canon ระหว่างการเขียนโดยพลการ
7. ก่อนจบบท ตรวจว่าใครรู้อะไรจาก [[continuity/knowledge-ledger]] และตรวจ Event anchors
8. ยังไม่เพิ่มบทพูดเข้า [[continuity/dialogue-ledger]] จนกว่าผู้สร้างอนุมัติต้นฉบับ

## Prompt เริ่มเขียน
เขียนต้นฉบับตอนที่ระบุจาก Chapter Note ในรีโป sakon9654/Hero โดยอ่าน Canon/Event/Knowledge links ล่าสุดก่อน รักษา Scene IDs และ continuity ทุกข้อ เขียนเป็นภาษาไทย แยกข้อความร้อยแก้วจากบันทึกกองบรรณาธิการอย่างชัดเจน รายละเอียดที่ยัง TBD ให้เลือกใช้ได้เฉพาะในฐานะ PROPOSED draft choice และสรุปสิ่งที่ต้องขอผู้สร้างยืนยันหลังจบบท ห้ามแก้ Canon ใหม่เอง

## Definition of done
- มีร้อยแก้วครบทุก Scene ID ของบท
- ไม่มีผู้รู้ข้อมูลก่อน Knowledge Event
- ไม่สับสน Mage Grade, Spell Tier, 3-star certification และใบอนุญาต
- ไม่ทำให้กลุ่มนักเรียนห้าคนไร้ฝีมือเพื่อขับเรน
- เวทของเรนไม่กลายเป็นระบบผสมเทค
- รายละเอียด Vesper ไม่เกิน Canon
