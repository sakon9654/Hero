# Continuity & Timeline — Hero

**ระบบควบคุมความต่อเนื่องของเนื้อเรื่อง** — ใช้ตรวจว่าเหตุการณ์เกิดก่อนหลังอย่างไร ตัวละครรู้อะไรเมื่อใด และมีคาถาใดใช้งานได้จริงแล้ว

## จุดอ้างอิงเวลา
- ใช้ **T0 = เวลาเริ่มบทที่ 1** (ยังไม่กำหนดวันเดือนปี)
- **T-** = ก่อนบทที่ 1; **T+** = หลังบทที่ 1
- ใช้หมายเลขเหตุการณ์ถาวร E001, E002, ... แม้ภายหลังย้ายตอน
- แยกสามเวลา: **เวลาเหตุการณ์ในโลก**, **บทที่เปิดเผยต่อผู้อ่าน**, **เวลาที่ตัวละครแต่ละคนรู้ข้อเท็จจริง**
- รายละเอียดที่ยังไม่ยืนยันให้ระบุ TBD ไม่กรอกตัวเลขหรือเหตุการณ์สมมติเป็น Canon

## แฟ้มระบบ
- [Timeline หลัก](timeline.md) — เหตุการณ์และลำดับก่อนหลัง
- [สถานะเรน](ren-state.md) — ความสามารถ/ข้อมูลที่แต่ละฝ่ายรู้/ใบรับรอง
- [แม่แบบทะเบียนคาถา](spell-registry-template.md) — ระดับคาถา/ความชำนาญ/เงื่อนไข/การเรียนและใช้ครั้งแรก

## กฎสำหรับการเขียนทุกบท
1. ก่อนเขียนตรวจสถานะตัวละคร ณ จุดเวลานั้น (Mage Grade จริง/ที่รับรู้, Spell Tier, ทะเบียนคาถา, ใบรับรอง)
2. คาถาใช้ได้ต่อเมื่อเคยเรียนและฝึกจนใช้ได้ภายในเวลานั้น ไม่ใช่เพราะ Codex มีข้อความของคาถา
3. หลังเขียนเพิ่มเหตุการณ์และผลกระทบ: ใครเห็นการใช้คาถา ใครได้เบาะแส เกรด/ใบรับรองเปลี่ยนหรือไม่
4. การเปิดเผยข้อมูลต่อผู้อ่านไม่เท่ากับการเปิดเผยต่อสภาหรือเพื่อน
5. หากมีการแก้ไขย้อนหลัง ต้องตรวจผลต่อเหตุการณ์ถัดไปและเก็บคำอธิบายการเปลี่ยนแปลง

## ยังไม่กำหนด
วันที่ T0, ช่วงห่างเวลาฝึกก่อนเริ่มเรื่อง, ตอนที่เข้าสถาบัน, เหตุผลที่สภารู้เพียง Grade 2, รายชื่อคาถาจริง
