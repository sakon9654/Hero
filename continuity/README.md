# Continuity & Timeline — Hero

ระบบควบคุมความต่อเนื่องของเนื้อเรื่อง ใช้ตรวจว่าเหตุการณ์เกิดก่อนหลังอย่างไร ตัวละครรู้อะไรเมื่อใด ความสัมพันธ์เปลี่ยนตรงไหน และมีบทสนทนาใดเปิดเผยข้อมูล

## จุดอ้างอิงเวลา
- ใช้ **T0 = เวลาเริ่มบทที่ 1** (ยังไม่กำหนดวันเดือนปี)
- **T-** = ก่อนบทที่ 1; **T+** = หลังบทที่ 1
- ใช้หมายเลขเหตุการณ์ถาวร E001, E002, ... แม้ภายหลังย้ายตอน
- แยกสามเวลา: เวลาเหตุการณ์ในโลก, บทที่เปิดเผยต่อผู้อ่าน, เวลาที่ตัวละครแต่ละคนรู้ข้อเท็จจริง
- รายละเอียดที่ยังไม่ยืนยันให้ระบุ TBD ไม่กรอกตัวเลขหรือเหตุการณ์สมมติเป็น Canon

## กฎสำหรับการเขียนทุกบท
1. ก่อนเขียนตรวจสถานะตัวละคร ณ จุดเวลานั้น
2. ตรวจ Knowledge Ledger ก่อนให้ตัวละครพูดหรือกระทำจากข้อมูลใด
3. คาถาใช้ได้ต่อเมื่อเคยเรียนและฝึกจนใช้ได้ภายในเวลานั้น
4. หลังเขียนเพิ่ม Event Note และอัปเดตผลต่อความสัมพันธ์ ความรู้ ใบรับรอง คาถา แผลหรือต้นทุน
5. การเปิดเผยต่อผู้อ่านไม่เท่ากับการเปิดเผยต่อสภา โรงเรียน หรือเพื่อน
6. หากแก้ย้อนหลัง ให้ตรวจ Event Notes ถัดไปและ backlinks ทั้งหมด
